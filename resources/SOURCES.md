# Тестовые документы

Современные офисные бланки для проверки OCR. Все ФИО, ИНН, адреса и суммы **вымышленные**.

| Файл | Тип |
| --- | --- |
| `zayavlenie_otpusk.png` | заявление на отпуск |
| `spravka_s_mesta_raboty.png` | справка с места работы |
| `nakladnaya_tovarnaya.png` | товарная накладная (фрагмент) |

Сгенерированы скриптом `_make_samples.py` (Pillow + Arial). Это не сканы чужих документов из интернета: так в репозитории нет персональных данных.

Исторический скан Конституции РСФСР из Wikimedia Commons убран — он не соответствует целевым сценариям (заявление / справка / накладная).

Повторная генерация:

```bat
python resources\_make_samples.py
```
